# Build & Distribution

> Assemble the Go server and Godot client into a runnable game distribution. The output is a single `dist/` directory that a player can launch with one command.

**Related skills:** ../SKILL.md (entry point), ../godot-engine/SKILL.md, ../websocket-api/06-server-setup.md

## Prerequisites

| Tool | Path | Purpose |
|------|------|---------|
| Go 1.24+ | `$GOROOT/bin/go` | Compile server binary |
| Godot 4.6+ | `/home/mturansk/Downloads/Godot_v4.6.3-stable_linux.x86_64` | Export client binary |
| CGO (gcc) | system | Required by `go-sqlite3` |
| Linux x86_64 | — | Target platform |

## Distribution Layout

```
dist/
├── rpg-server              # Go WebSocket server binary
├── hex-world-rpg.x86_64   # Godot client binary (PCK embedded)
├── hex-world-rpg.sh        # Console wrapper (generated by Godot export)
├── rpg.db                  # SQLite database (created on first server run)
└── run.sh                  # Launch script: starts server, opens client
```

## Build Steps

### 1. Build Server

```bash
cd server
go build -o ../dist/rpg-server ./cmd/rpg-server/
```

Verify: `./dist/rpg-server --help` or `file dist/rpg-server` shows ELF x86-64.

### 2. Export Client

```bash
rm -f client-godot/.godot/imported/*.sqlite*

/home/mturansk/Downloads/Godot_v4.6.3-stable_linux.x86_64 \
  --headless \
  --path client-godot/ \
  --export-release "Linux" \
  ../dist/hex-world-rpg.x86_64
```

The export preset (`client-godot/export_presets.cfg`) embeds the PCK into the binary. Output is a self-contained executable.

Verify: `file dist/hex-world-rpg.x86_64` shows ELF x86-64.

### 3. Create Launch Script

```bash
cat > dist/run.sh << 'LAUNCH'
#!/usr/bin/env bash
set -euo pipefail
DIR="$(cd "$(dirname "$0")" && pwd)"

cleanup() {
    if [ -n "${SERVER_PID:-}" ]; then
        kill "$SERVER_PID" 2>/dev/null || true
        wait "$SERVER_PID" 2>/dev/null || true
    fi
}
trap cleanup EXIT INT TERM

"$DIR/rpg-server" -addr :8080 -db "$DIR/rpg.db" &
SERVER_PID=$!

sleep 1

if ! kill -0 "$SERVER_PID" 2>/dev/null; then
    echo "Server failed to start"
    exit 1
fi

echo "Server running on :8080 (PID $SERVER_PID)"
echo "Launching client..."

"$DIR/hex-world-rpg.x86_64"

cleanup
LAUNCH
chmod +x dist/run.sh
```

### 4. Verify Distribution

```bash
ls -lh dist/
file dist/rpg-server dist/hex-world-rpg.x86_64
dist/rpg-server -addr :0 -db :memory: &  # smoke test, :0 picks random port
kill $!
```

## One-Line Build

```bash
mkdir -p dist && \
cd server && go build -o ../dist/rpg-server ./cmd/rpg-server/ && cd .. && \
/home/mturansk/Downloads/Godot_v4.6.3-stable_linux.x86_64 --headless --path client-godot/ --export-release "Linux" dist/hex-world-rpg.x86_64
```

## One-Line Run

```bash
dist/run.sh
```

## Reconciliation Check

Compare against this skill when verifying distribution readiness:

| Check | Pass Condition |
|-------|---------------|
| Server binary exists | `file dist/rpg-server` → ELF 64-bit x86-64 |
| Client binary exists | `file dist/hex-world-rpg.x86_64` → ELF 64-bit x86-64 |
| Launch script exists | `test -x dist/run.sh` |
| Server starts cleanly | `dist/rpg-server -addr :8080 -db dist/rpg.db` prints `[STARTUP]` |
| Client connects | Client shows connect screen, WebSocket handshake succeeds |
| All tests pass first | `./test.sh` exits 0 before building dist |

## Clean

```bash
rm -rf dist/
rm -f client-godot/build/rpg-server client-godot/build/hex-world-rpg.x86_64
rm -f client-godot/build/rpg.db*
```

## Cross-Platform (Future)

The export presets currently define Linux only. To add Windows/macOS:

1. Add presets in `client-godot/export_presets.cfg`
2. Cross-compile Go server: `GOOS=windows GOARCH=amd64 go build ...`
3. Add platform-specific launch scripts (`run.bat`, `run.command`)
4. Update this skill with per-platform steps
